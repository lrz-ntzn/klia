# Kian Korean

English to Korean learning PWA.

## Features
- Flashcard decks for pronouns, verbs, particles, Sino and native numbers, colors, days, months, and time
- Shared card engine: reveal, type, or pick; missed cards return sooner; per-deck progress in localStorage
- Hangul plus an anglicized spelling on every Korean answer, and IPA only for sounds English lacks
- Korean playback (ko-KR speechSynthesis) on each card
- Sentence builder: drag tiles into SOV order, with English SVO shown beside Korean SOV, including pronoun drops
- More practice: Hangul flash cards, fast-read drill, sound chart, vocab, and mic check
- Offline via service worker

## Run locally
```bash
python3 -m http.server 8765
# open http://localhost:8765
```
Mic needs HTTPS on a phone (or localhost).
